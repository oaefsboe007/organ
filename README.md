# Virtual Pipe Organ

Free browser pipe organ: 5 manuals, 32-note pedalboard, 200+ stops, couplers, swell shoes, crescendo, tremulants, reverb, temperaments, Web MIDI.

**Play:** https://oaefsboe007.github.io/organ/

Single file (`index.html`), no dependencies. MIDI: ch1 pedal, ch2 Choir, ch3 Great, ch4 Swell, ch5 Solo, ch6 Echo; CC11 expression, CC64 sustain, program change = general piston.
